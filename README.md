# Muhammad Ahsan Khan — Portfolio Website

A responsive static portfolio prepared for GitHub Pages.

## Launch

1. Create a new GitHub repository (recommended name: `ahsankhan-portfolio`).
2. Upload/commit these files to the repository root.
3. In GitHub: **Settings → Pages → Deploy from a branch → main / root**.
4. Add a custom domain later if desired.

## Important before publishing

- Replace the CSS-generated project preview artwork with approved high-resolution exports from your actual portfolio.
- Confirm portfolio/client permissions before republishing commissioned work.
- Upwork metrics are a snapshot from October 2026 and should be reviewed periodically.
- Contact email currently uses the email returned by the connected GitHub profile. Change it if you prefer a dedicated business address.

## Files

- `index.html` — homepage
- `work.html` — filtered project archive
- `services.html` — service offering
- `about.html` — bio / credibility
- `contact.html` — project inquiry routes
- `work/*.html` — case-study shells
- `assets/style.css` — design system and responsive styles
- `assets/app.js` — filtering + restrained reveal interactions
